# Arrmy covers daily operations and links out for settings

Arrmy handles Requests, Problems (with one-click fixes), stats and the live queue across every Service. Everything else (quality profiles, indexers, naming, per-Service settings) opens that Service's own UI. We rejected re-implementing each Service's settings in Arrmy: that is months of work per Service, it breaks whenever a Service changes its API, and the Admin only opens those screens a few times a year.
