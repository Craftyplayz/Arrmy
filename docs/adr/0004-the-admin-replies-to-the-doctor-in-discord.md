# The Admin replies to The Doctarr in Discord, which Arrmy reads

The Discord bot only reported until now. When The Doctarr can't solve a Problem, the Admin can now reply in its thread in plain words, and The Doctarr carries on its own Claude Code conversation (`--resume`) and acts on what they say. Discord never sends a bot ordinary messages, so Arrmy reads the threads waiting on the Admin every 20 seconds through Discord's API, with the bot's Message Content Intent switched on. We rejected the Gateway (a websocket kept open all the time, with heartbeats and reconnects) because it would be Arrmy's first always-open connection, for replies that can wait 20 seconds; and a `/reply` slash command, which needs no reading but means remembering a command. Only `DISCORD_ADMIN_ID`'s words count as instructions. The Doctarr still changes things only through the fixes in `scripts/doctor.mjs` (no shell, no Docker: ADR 0001); a few of them (grab a release by number, look again later, stop monitoring, remove a Request, delete a torrent) only run while it is answering the Admin, and the two that can't be undone wait for the Admin's click on a button.
