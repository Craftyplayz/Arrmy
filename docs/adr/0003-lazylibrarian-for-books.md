# LazyLibrarian fills Book, Audiobook and Periodical Requests

Readarr was retired in 2025. We chose LazyLibrarian over the Readarr forks (Chaptarr, Bookshelf), even though the forks share the Radarr/Sonarr API shape and would reuse Arrmy's adapter code. LazyLibrarian is maintained, and one instance covers Books, Audiobooks and Periodicals, while Chaptarr is beta and Bookshelf needs separate instances for ebooks and audiobooks. The cost is a dedicated LazyLibrarian adapter.
